## What it does

`main.py` (stdlib-only Python) writes one single-line passive-aggressive note
from a smart fridge to its owner into `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

## Run

```sh
python3 main.py
```
